# AI Combats

Este repositório contém projetos de demonstração criados por diferentes modelos de IA. Todos os projetos são aplicações web estáticas (HTML/CSS/JS) que podem ser executados facilmente em um servidor local.

## 🚀 Como Rodar os Projetos

### Opção 1: Usando http-server (Recomendado)

1. **Instale o http-server globalmente:**
   ```cmd
   npm install -g http-server
   ```

2. **Navegue até o diretório do projeto:**
   ```cmd
   cd paralax-starfield\claude 4.5 sonnet
   ```

3. **Execute o servidor:**
   ```cmd
   http-server
   ```

4. **Acesse no navegador:**
   - Geralmente disponível em: `http://localhost:8080`

### Opção 2: Abrindo Diretamente

Você também pode abrir o arquivo `index.html` diretamente no navegador, mas alguns recursos podem não funcionar corretamente sem um servidor HTTP.
