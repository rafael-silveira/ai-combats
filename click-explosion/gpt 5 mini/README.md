# Explosões ao Clique — Bola de Fogo

Arquivos HTML/CSS/JS simples que criam uma animação de "bola de fogo" a cada clique do mouse.

Como usar
- Abra `index.html` em um navegador moderno (Chrome, Edge, Firefox, Safari).
- Clique ou toque em qualquer lugar da janela para ver uma explosão.

Notas
- Apenas HTML/CSS/JS puros — sem dependências.
- Recomendado testar em desktop e mobile. Para reduzir movimento, habilite a preferência de sistema "Reduzir movimento".
