# Click Explosion

Animação simples em HTML, CSS e JavaScript puro que gera uma explosão estilizada parecida com uma bola de fogo em cada clique do mouse (ou toque em dispositivos compatíveis). Cada explosão nasce no ponto clicado, expande e desaparece de forma suave.

## Como usar

1. Abra o arquivo `index.html` diretamente no navegador (duplo clique já funciona).
2. Clique ou toque em qualquer lugar da tela para criar explosões brilhantes.

## Estrutura

- `index.html` — Marca a estrutura básica da página e carrega os estilos e a lógica.
- `styles.css` — Define o visual do cenário e da animação da explosão.
- `script.js` — Captura os cliques/toques e cria/remover os elementos animados.

## Dicas

- Segure o botão do mouse e mova-o pela tela para criar um rastro de explosões.
- Ajuste os valores em `styles.css` (como tamanhos e cores das gradientes) para experimentar variações de efeito.
