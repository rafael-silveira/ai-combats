# Click Explosion

Pequena demo em HTML/CSS/JS onde cada clique gera uma explosão tipo bola de fogo que some. Basta abrir `index.html` em um navegador.

Como testar:

1. Abra `index.html` no navegador.
2. Clique em qualquer lugar na área para gerar uma explosão.

Notas:
- Feito sem dependências externas.
- Ajuste cores e tamanhos em `style.css`.
