# Parallax Starfield

Uma animação de campo de estrelas com efeito parallax inspirada nos menus e jogos de arcade dos anos 80/90, criada apenas com HTML, CSS e JavaScript puro.

## ✨ Recursos

- Três camadas de estrelas com velocidades e tamanhos diferentes para reforçar a sensação de profundidade.
- Brilho pulsante (twinkle) e leve gradiente nas estrelas para um visual mais "retro futurista".
- Pequena inclinação do campo de visão conforme o movimento do mouse ou toque.
- Totalmente responsivo e otimizado para telas HiDPI.

## 🚀 Como executar

Basta abrir o arquivo `index.html` diretamente no navegador de sua preferência. Nenhuma dependência ou build é necessária.

## 🛠️ Estrutura

```
index.html   # marcação principal e inclusão dos assets
style.css    # estilos e overlay da HUD
script.js    # lógica de animação e interação
```
