# Parallax Starfield Animation

This is a simple parallax starfield animation inspired by 80s and 90s 16-bit games, created using only HTML, CSS, and JavaScript.

## How to Run

1. Open `index.html` in a web browser.
2. The animation will start automatically, showing stars moving across the screen with parallax effect.

## Features

- Black background
- Stars in white tones
- Three layers of stars with different speeds for parallax effect
- Stars reset to the right when they move off-screen

## Troubleshooting

- If the animation doesn't load, ensure JavaScript is enabled in your browser.
- For best performance, use a modern browser.
